# 数据集说明

更完整的数据集目录、内容可见性和课程选型建议，请阅读 [`catalog.md`](catalog.md)。

本项目只保存数据集的说明、下载入口和处理脚本，不保存原始数据文件。

## MovieLens

- 官方入口：https://grouplens.org/datasets/movielens/
- 入门推荐：MovieLens 100K
- 进阶推荐：MovieLens 1M、20M 或 32M
- 许可：下载并使用前请阅读对应压缩包中的 README 和使用条款

## Amazon Reviews

- 官方入口：https://mcauleylab.ucsd.edu/public_datasets/data/amazon/datasets.html
- 推荐先选择一个较小的商品类别，不要直接处理全量数据
- 可用于评分、隐式反馈、评论文本和冷启动实验

## Yelp Open Dataset

- 官方入口：https://business.yelp.com/data/resources/open-dataset/
- 可用于商户推荐、地理位置推荐、评论文本和多样性分析
- 使用前请确认当前下载条件和许可范围

## MIND

- 官方介绍：https://www.microsoft.com/en-us/research/publication/mind-a-large-scale-dataset-for-news-recommendation/
- 项目与评测代码：https://github.com/msnews/MIND
- 适合新闻点击预测、序列推荐和用户兴趣建模

## 课程原则

学生提交时必须记录：数据集名称、版本或下载日期、数据规模、预处理步骤、切分方式和数据许可。
