# 课程项目要求

## 题目

基于一个公开推荐数据集，设计并实现一个可复现的推荐系统方案。项目重点不是堆叠复杂模型，而是说明问题定义、数据处理、模型选择、实验设计和结果解释之间的关系。

## 最低要求

- 一个可运行的 baseline
- 一个改进方法或模型
- 合理的数据切分与负采样策略
- 至少三项 Top-K 指标
- 至少一组消融或敏感性实验
- 对失败案例、冷启动或长尾问题进行分析

## 评分建议

| 项目 | 占比 |
|---|---:|
| 数据处理与可复现性 | 20% |
| baseline 与方法实现 | 25% |
| 实验设计与指标 | 25% |
| 分析、可视化与讨论 | 20% |
| 代码规范与报告表达 | 10% |
